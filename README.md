** Threat Hunting Project: PowerShell C2 Detection**

This project demonstrates a proactive threat hunt conducted on the Splunk BOTS v3 dataset, focused on detecting malicious PowerShell activity, decoding obfuscated commands, and correlating network logs to confirm a command-and-control compromise. Rather than waiting for an alert, I began with a hypothesis: an adversary may be using encoded PowerShell to evade detection. I searched Windows event logs and network traffic in Splunk and uncovered a Base64-encoded PowerShell command, which I decoded using CyberChef. The decoded script disabled key Windows security controls (AMSI and Script Block Logging) and attempted to communicate with a hardcoded C2 server at 45.77.53.176. Pivoting back into Splunk, I confirmed that a host on the network had actually communicated with that IP, establishing the correlation needed to validate the compromise. The investigation identified the malicious IP (45.77.53.176) and C2 URL (https://45.77.53.176:443/login/process.php) tied to the compromised host, classifying the attack as an encoded PowerShell C2 beacon rated Critical in severity. The repository is organized into four components: the full investigation report (THREAT-HUNT-REPORT.md), the decoded malicious script (decoded-payload.txt), all Splunk queries used (queries/), and visual evidence captured at each stage (screenshots/). The hunt was carried out using Splunk Enterprise (Free), CyberChef for Base64 decoding, and the MITRE ATT&CK Framework for technique mapping, demonstrating my ability to hunt for threats, analyze malicious scripts, correlate network activity, and document findings in a clear, professional format.
